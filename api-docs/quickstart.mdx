title: "Quickstart"
description: "Create a customer, invoice them and email the invoice in under 5 minutes."
icon: "bolt"
---

<Note>
  Before you start, finish your business profile and verify your email address in the [Invoice-AI app](https://invoice.horizonpay.co). Sending invoice emails requires a verified address.
</Note>

<Steps>
  <Step title="Get an API key">
    In [Settings → API keys](https://invoice.horizonpay.co/settings/api-keys), create a key with the **Raise and send invoices** preset. Copy it now. It's shown only once.

    ```bash
    export INVOICE_AI_API_KEY="inv_live_..."
    ```

    To use an SDK, install it:

    <CodeGroup>
    ```bash Node.js
    npm install @horizonpay/invoice-ai
    ```

    ```bash Python
    pip install horizonpay-invoice-ai
    ```
    </CodeGroup>
  </Step>

  <Step title="Create a customer">
    Use an email address you control, so the invoice lands in your own inbox.

    <CodeGroup>
    ```bash cURL
    curl https://invoice.horizonpay.co/api/v1/customers \
      -H "Authorization: Bearer $INVOICE_AI_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{ "name": "Acme Ltd", "email": "billing@acme.example" }'
    ```

    ```ts Node.js
    import InvoiceAI from '@horizonpay/invoice-ai'

    const invoiceai = new InvoiceAI() // reads INVOICE_AI_API_KEY

    const customer = await invoiceai.customers.create({
      name: 'Acme Ltd',
      email: 'billing@acme.example',
    })
    ```

    ```python Python
    from invoice_ai import InvoiceAI

    client = InvoiceAI()  # reads INVOICE_AI_API_KEY

    customer = client.customers.create(name="Acme Ltd", email="billing@acme.example")
    ```
    </CodeGroup>

    Keep the customer's `id`. It looks like `cus_Nf3kQ8pR2mX7vB1cT9wL4sZ6`.
  </Step>

  <Step title="Create a draft invoice">
    Add one line. `unit_amount` is in minor units, so `150000` is $1,500.00.

    <CodeGroup>
    ```bash cURL
    curl https://invoice.horizonpay.co/api/v1/invoices \
      -H "Authorization: Bearer $INVOICE_AI_API_KEY" \
      -H "Content-Type: application/json" \
      -H "Idempotency-Key: $(uuidgen)" \
      -d '{
        "customer": "cus_Nf3kQ8pR2mX7vB1cT9wL4sZ6",
        "currency": "USD",
        "days_until_due": 14,
        "items": [{ "description": "Design retainer", "quantity": 1, "unit_amount": 150000 }]
      }'
    ```

    ```ts Node.js
    const invoice = await invoiceai.invoices.create({
      customer: customer.id,
      currency: 'USD',
      days_until_due: 14,
      items: [{ description: 'Design retainer', quantity: 1, unit_amount: 150000 }],
    })
    ```

    ```python Python
    invoice = client.invoices.create(
        customer=customer.id,
        currency="USD",
        days_until_due=14,
        items=[{"description": "Design retainer", "quantity": 1, "unit_amount": 150000}],
    )
    ```
    </CodeGroup>

    ```json Response (abridged)
    {
      "data": {
        "id": "in_Pb2Xk7Mv4Qs9Lr1Wd6Tn3Fh8",
        "object": "invoice",
        "status": "draft",
        "number": null,
        "customer": "cus_Nf3kQ8pR2mX7vB1cT9wL4sZ6",
        "currency": "USD",
        "total": 150000,
        "amount_due": 0
      }
    }
    ```

    Creating an invoice needs an [`Idempotency-Key`](/idempotency) header. The SDKs add one for you.
  </Step>

  <Step title="Finalize it">
    Finalizing gives the invoice its permanent number and moves it to `open`.

    <CodeGroup>
    ```bash cURL
    curl -X POST https://invoice.horizonpay.co/api/v1/invoices/in_Pb2Xk7Mv4Qs9Lr1Wd6Tn3Fh8/finalize \
      -H "Authorization: Bearer $INVOICE_AI_API_KEY" \
      -H "Idempotency-Key: $(uuidgen)"
    ```

    ```ts Node.js
    const finalized = await invoiceai.invoices.finalize(invoice.id)
    console.log(finalized.number) // "INV-0042"
    ```

    ```python Python
    finalized = client.invoices.finalize(invoice.id)
    print(finalized.number)  # "INV-0042"
    ```
    </CodeGroup>

    You can skip this step. `send` finalizes a draft before emailing it.
  </Step>

  <Step title="Send it">
    This emails the PDF and a link to view the invoice online to the customer's email.

    <CodeGroup>
    ```bash cURL
    curl -X POST https://invoice.horizonpay.co/api/v1/invoices/in_Pb2Xk7Mv4Qs9Lr1Wd6Tn3Fh8/send \
      -H "Authorization: Bearer $INVOICE_AI_API_KEY" \
      -H "Idempotency-Key: $(uuidgen)"
    ```

    ```ts Node.js
    const { emailed_to } = await invoiceai.invoices.send(invoice.id)
    ```

    ```python Python
    sent = client.invoices.send(invoice.id)
    print(sent.emailed_to)
    ```
    </CodeGroup>

    The response is `{ "data": Invoice, "emailed_to": "billing@acme.example" }`. Pass `{ "to": "..." }` to send to a different address.

    Sending is limited to 10 emails per hour per key and 50 per hour per account. See [Rate limits](/rate-limits).
  </Step>
</Steps>

When the customer pays, call `POST /invoices/{id}/pay` to mark the invoice paid. See [Invoice lifecycle](/invoice-lifecycle).
