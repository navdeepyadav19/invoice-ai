The Invoice-AI API lets your code do what you do in the [Invoice-AI app](https://invoice.horizonpay.co): add customers, create invoices, email them and mark them paid.

- **Base URL:** `https://invoice.horizonpay.co/api/v1`
- **Auth:** send an API key as a Bearer token. Create one in [Settings → API keys](https://invoice.horizonpay.co/settings/api-keys).
- **Money:** integers in minor units, so `2500` is $25.00.

```bash
curl https://invoice.horizonpay.co/api/v1/business \
  -H "Authorization: Bearer $INVOICE_AI_API_KEY"
```
