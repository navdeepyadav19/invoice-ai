The Invoice-AI API lets your code do what you do in the [Invoice-AI app](https://invoice.horizonpay.co): add customers, create invoices, email them and mark them paid.

```bash
curl https://invoice.horizonpay.co/api/v1/business \
  -H "Authorization: Bearer inv_live_…"
```

## Three things to know

1. **Base URL:** `https://invoice.horizonpay.co/api/v1`
2. **Auth:** send your API key as a Bearer token. Create one in [Settings → API keys](https://invoice.horizonpay.co/settings/api-keys).
3. **Money** is in the smallest unit, so `2500` means $25.00.
