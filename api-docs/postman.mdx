<Steps>
  <Step title="Fork it">
    Click **Run in Postman** and fork the **Invoice-AI API v1** collection and the **Invoice-AI — production** environment into your workspace.
  </Step>
  <Step title="Add your key">
    Create a key in [Settings → API keys](https://invoice.horizonpay.co/settings/api-keys) with every scope and a short expiry. In the **Invoice-AI — production** environment, paste it into `api_key`.
  </Step>
  <Step title="Run the collection">
    Open the **Collection Runner** and run the whole collection in order. Each request uses ids saved by the ones before it.
  </Step>
</Steps>

You can also browse it in the [public workspace](https://www.postman.com/gold-meadow-6657-1/invoice-ai-api/overview) without forking.

## Without a Postman account

Import the files from the repository: in Postman, choose **Import → Link** and paste each URL.

| File | Contents |
|---|---|
| [`invoice-ai.postman_collection.json`](https://raw.githubusercontent.com/navdeepyadav19/invoice-ai/main/docs/platform/postman/invoice-ai.postman_collection.json) | Every request, in run order, with tests |
| [`invoice-ai.postman_environment.json`](https://raw.githubusercontent.com/navdeepyadav19/invoice-ai/main/docs/platform/postman/invoice-ai.postman_environment.json) | `base_url` and `api_key` |

Or use [Newman](https://github.com/postmanlabs/newman):

```bash
newman run invoice-ai.postman_collection.json \
  -e invoice-ai.postman_environment.json \
  --env-var api_key=inv_live_...
```

<Warning>
  A run creates real, numbered invoices in your account and sends one real email to `delivered@resend.dev`. That email counts toward your [send limits](/rate-limits), and your account email must be verified.
</Warning>

Maintainers: `pnpm postman:gen` regenerates the files after an API change, and the **Postman sync** workflow republishes them to the public workspace when they reach `main`. The button follows the published collection.
