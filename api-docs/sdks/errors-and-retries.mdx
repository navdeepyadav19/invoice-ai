## Retries are automatic

Failed calls are retried up to **2 times**, with exponential backoff from 0.5s up to 8s. The SDK retries on:

- network errors and timeouts
- `408`, `409 conflict` and any `5xx`
- `429`, after waiting for `Retry-After`

Every `POST` gets an `Idempotency-Key`, and retries reuse it, so a retried "create invoice" never creates two. `PATCH` and `DELETE` have no key, so they're only retried when the request never reached the server, or on `429`.

Change this per client or per call:

<CodeGroup>
```ts TypeScript
const invoiceai = new InvoiceAI({ maxRetries: 5, timeout: 20_000 }) // ms
await invoiceai.invoices.finalize(id, { idempotencyKey: 'order-1234' })
```
```python Python
client = InvoiceAI(max_retries=5, timeout=20.0)  # seconds
client.invoices.finalize(id, idempotency_key="order-1234")
```
</CodeGroup>

## Catch errors by type

<CodeGroup>
```ts TypeScript
import { InvalidStateError, ValidationError } from '@horizonpay/invoice-ai'

try {
  await invoiceai.invoices.void(id, { reason: 'Duplicate' })
} catch (err) {
  if (err instanceof InvalidStateError) console.log('Only open invoices can be voided')
  else if (err instanceof ValidationError) console.log(err.fields)
  else throw err
}
```
```python Python
from invoice_ai import InvalidStateError, ValidationError

try:
    client.invoices.void(id, reason="Duplicate")
except InvalidStateError:
    print("Only open invoices can be voided")
except ValidationError as err:
    print(err.fields)
```
</CodeGroup>

| Error | When |
|---|---|
| `AuthenticationError` | Missing or invalid API key (`401`) |
| `PermissionError` | The key lacks the scope (`403`). Python calls it `PermissionDeniedError`, with `PermissionError` as an alias. |
| `NotFoundError` | No such object (`404`) |
| `InvalidStateError` | Wrong state, such as editing a finalized invoice (`409`) |
| `ConflictError` | Clashed with a concurrent request (`409`) |
| `ValidationError` | Bad input. See `.fields` (`422`) |
| `RateLimitError` | Too many requests, even after retries (`429`) |
| `APIConnectionError` | No response: network failure or timeout (`APITimeoutError`) |

All of them extend `InvoiceAIError`. API errors carry `status`, `code`, `detail` and the request id (`requestId` in TypeScript, `request_id` in Python). Include the request id when you contact support.

See [Errors & retries](/errors) for every error code.
