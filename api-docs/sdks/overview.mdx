The SDKs wrap the API, so you call `invoices.create(...)` instead of writing HTTP requests. They also handle retries, idempotency keys, pagination and errors for you.

## Install

Requires **Node 20+** or **Python 3.10+**.

<CodeGroup>
```bash TypeScript
npm install @horizonpay/invoice-ai
```
```bash Python
pip install horizonpay-invoice-ai
```
</CodeGroup>

## First call

Set `INVOICE_AI_API_KEY` in your environment, then:

<CodeGroup>
```ts TypeScript
import InvoiceAI from '@horizonpay/invoice-ai'
// CommonJS: const { InvoiceAI } = require('@horizonpay/invoice-ai')

const invoiceai = new InvoiceAI()

const customer = await invoiceai.customers.create({ name: 'Acme', email: 'ap@acme.com' })
const invoice = await invoiceai.invoices.create({
  customer: customer.id,
  currency: 'USD',
  items: [{ description: 'Consulting', quantity: 1, unit_amount: 250000 }],
})
await invoiceai.invoices.send(invoice.id) // finalizes, then emails
```
```python Python
from invoice_ai import InvoiceAI

client = InvoiceAI()

customer = client.customers.create(name="Acme", email="ap@acme.com")
invoice = client.invoices.create(
    customer=customer.id,
    currency="USD",
    items=[{"description": "Consulting", "quantity": 1, "unit_amount": 250000}],
)
client.invoices.send(invoice.id)  # finalizes, then emails
```
</CodeGroup>

Every endpoint in the [API reference](/api-reference/introduction) shows its TypeScript and Python call.

## Lists

Loop over a list, and the SDK fetches the next pages for you.

<CodeGroup>
```ts TypeScript
for await (const invoice of invoiceai.invoices.list({ status: 'open' })) {
  console.log(invoice.number)
}
```
```python Python
for invoice in client.invoices.list(status="open"):
    print(invoice.number)
```
</CodeGroup>

For `async`/`await` code, Python also has `AsyncInvoiceAI`.

## Client options

| TypeScript | Python | Default |
|---|---|---|
| `apiKey` | `api_key` | `INVOICE_AI_API_KEY` |
| `baseURL` | `base_url` | `INVOICE_AI_BASE_URL`, then `https://invoice.horizonpay.co/api/v1` |
| `timeout` (**milliseconds**) | `timeout` (**seconds**) | `60000` / `60.0`, per attempt |
| `maxRetries` | `max_retries` | `2` |
| `logLevel` | `log_level` | `INVOICE_AI_LOG`, then `warn`. Set `debug` to log every request (secrets redacted). |
| `fetch` | `http_client` | Global `fetch` / a new `httpx.Client` |

`timeout`, `maxRetries` (`max_retries`) and `idempotencyKey` (`idempotency_key`) can also be set per call. See [Errors & retries](/sdks/errors-and-retries).
